# Comparative NLP Analysis of English Text and Russian Translation

## About the project

This educational project focuses on the comparative NLP analysis of an English text and its Russian translation.

The goal of the project is to explore differences between the original and translated texts using methods of natural language processing and to compare their lexical, morphological, syntactic, semantic and emotional characteristics.

## Analysis

The project includes:

- text preprocessing;
- tokenization;
- stop-word removal;
- stemming and lemmatization;
- word frequency analysis;
- text visualization;
- word cloud generation;
- morphological and syntactic analysis;
- sentiment analysis;
- semantic similarity analysis of the original and translated texts.

## Technologies

- spaCy
- pymorphy3
- Transformers
